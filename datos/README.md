# Procedencia de datos

Estos archivos contienen muestras didacticas para probar DataDSL; no tienen una fuente externa documentada. No deben presentarse como datos reales de una entidad.

- `ventas.csv`: carga, nulos, filtros y duplicados.
- `regresion.csv`: precios segun metros y habitaciones.
- `clasificacion.csv`: aprobacion segun estudio y sueno.
- `clientes.csv`: segmentacion por frecuencia y ticket.
- `numeros.csv`: numeros enteros para ejercicios.

Cada CSV lleva una nota inicial que el lector propio de DataDSL ignora antes de leer el encabezado.
